# Установка Termux Assistant AI

Пошаговая инструкция для нового пользователя. Всё занимает ~15 минут.

## Шаг 1 — Termux (F-Droid)

**Termux нет в Google Play** — Google запретил его в 2020. Ставим из F-Droid.

1. Открой https://f-droid.org/packages/com.termux/
2. Скачай APK Termux
3. Установи (разреши установку из браузера)

**ВАЖНО:** только F-Droid-версия. Play Market не поддерживается.

## Шаг 2 — Termux:API (F-Droid)

1. Открой https://f-droid.org/packages/com.termux.api/
2. Скачай и установи APK

Без Termux:API не работают команды:
- `termux-toast` (всплывающие сообщения)
- `termux-notification` (уведомления)
- `termux-wifi-enable` (опционально)

## Шаг 3 — DeepSeek (Play Market)

Открой Play Market → найди **DeepSeek** → установи.

## Шаг 4 — Termux Assistant AI

Скачай APK и установи. При первом запуске:

1. Приложение запросит **MANAGE_EXTERNAL_STORAGE** → **Разрешить**
2. Запросит **RECORD_AUDIO** (микрофон) → **Разрешить**
3. Запросит **уведомления** → **Разрешить**

## Шаг 5 — Разрешения через систему

Если не все разрешения запрошены автоматически:

**Настройки → Приложения → Termux Assistant AI → Разрешения**
- **Микрофон** → Разрешить
- **Файлы и медиа** → Разрешить управление всеми файлами

## Шаг 6 — Accessibility-сервис

1. Открой **Termux Assistant AI → Настройки**
2. Раздел **AI Bridge Service** — увидишь три статуса
3. Жми **«Открыть специальные возможности»**
4. Найди **AI Bridge Service**
5. Попробуй включить тумблер
6. **Если пишет «Ограниченные настройки»:**
   - Вернись в Tasker → Настройки
   - Жми **«Открыть настройки приложения»**
   - Правый верхний угол → **⋮**
   - **«Разрешить ограниченные настройки»** → подтверди PIN
   - Снова открой спец. возможности → тумблер включится

## Шаг 7 — Termux: первый запуск

Открой Termux. Внутри:

    pkg update && pkg upgrade
    pkg install python termux-api aapt2 d8 apksigner openjdk-21 zip unzip
    termux-setup-storage

(Подтверди доступ к памяти когда спросит.)

## Шаг 8 — Развёртывание инфраструктуры

**Вариант A (если тебе дали готовый бэкап):**

    cd ~
    # скачай и распакуй бэкап в ~/backups/
    cp -r ~/backups/latest/bin/* ~/bin/
    cp -r ~/backups/latest/ai-tasker-app ~/projects/termux-ai-kit/
    mkdir -p ~/projects/ai-sandbox
    aictl-up

**Вариант B (если настраиваешь с нуля):**

Смотри DEV_GUIDE.md — там всё про создание инфраструктуры с нуля.

## Шаг 9 — Проверка

В Termux:

    aictl-up          # подъём receiver + watchdog
    aictl status      # порты должны быть OK
    aib ping          # должен быть PONG

В приложении Tasker:

- Открой **Настройки** → все три статуса должны быть **✓**
- Введи **uptime** → Выполнить → через 1-2 сек результат

## Частые проблемы

| Проблема | Решение |
|---|---|
| Termux не ставится | Скачай F-Droid APK, установи из него |
| `Connection refused` | Accessibility-сервис не включён |
| Приложение пишет «Ограниченные настройки» | См. Шаг 6 |
| DeepSeek не отвечает | Открой приложение DeepSeek вручную |
| Голос не работает | Настройки → Приложения → Tasker → Микрофон |
