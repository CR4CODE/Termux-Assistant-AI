# Termux Assistant AI — Roadmap

## ✅ Сделано

### v1.0 — базовая версия
- UI: поле ввода, кнопка Выполнить
- История задач с обновлением каждые 3 сек
- Связь через /sdcard/ai-tasker/{inbox,outbox}

### v1.1 — маршрутизация
- bash-router (uptime, df, ls — 1 сек)
- intent-router (открой вк, ютуб)
- url-router (открой гитхаб, google.com)
- ai-router (DeepSeek для сложных задач)

### v1.2 — UX
- Длительность задач
- Модалка с полным выводом
- Кнопки: Повторить / Копировать / Удалить
- Долгий тап → удалить
- Прогресс-бар для running
- Уведомления при завершении

### v1.3 — голосовой ввод
- Кнопка 🎤
- SpeechRecognizer ru-RU
- Разрешение RECORD_AUDIO

### v1.4 — темы
- 3 темы: светлая / тёмная / системная
- attrs.xml + ?attr/app* в layouts
- recreate() при смене

### v1.5 — объединение APK
- AiBridgeService внутри Tasker
- Один пакет com.termux.assistant
- Автозапрос разрешений
- Блок AI Bridge Service в Настройках с ✓/✗
- Кнопки «Открыть спецвозможности» / «Открыть настройки приложения»
- Встроенная инструкция по включению сервиса

### Документация
- README.md
- INSTALL.md
- USER_GUIDE.md
- DEV_GUIDE.md
- TERMUX_COMMANDS.md

### Инфраструктура
- ai-tasker-daemon (следит за inbox)
- ai-router (маршрутизация)
- ai-dev (автономная разработка APK)
- build.sh (сборка одной командой)
- aictl-up (подъём после ребута)
- watchdog + logrotate

## ⏳ В планах

### Wizard первого запуска
- Приветственный экран
- Пошаговая проверка Termux/API/DeepSeek/Сервис
- Кнопки «Открыть F-Droid» / «Открыть Play Market»
- Автопроверка готовности

### ai-dev в UI
- Кнопка «Улучшить это приложение» в Настройках
- Запуск ai-dev из интерфейса
- Просмотр diff
- Кнопки «Применить / Откатить»

### Встроенная инструкция
- Кнопка «Инструкция» в Настройках
- Показывает README/INSTALL/USER_GUIDE внутри приложения

### Прочее (низкий приоритет)
- Импорт / экспорт истории задач
- Виджет на домашний экран
- Шаблоны задач (сохранённые)
- Расписание / триггеры
- Whitelist команд для безопасности
