# Termux Assistant AI

**AI-ассистент для Android** — работает в связке с **DeepSeek** через **Termux**.
Управляет приложениями, выполняет команды, читает экран и **сам разрабатывает код**.

> Без root. Без API-ключей. Без Wi-Fi-ADB. Только Termux + accessibility.

---

## Возможности

### 🎯 Три режима ввода

| Ввод | Пример | Скорость |
|---|---|---|
| **Голос** 🎤 | «открой вк», «покажи uptime» | мгновенно |
| **Текст** | открой гитхаб, df -h, ls ~/projects | 1-2 сек |
| **AI-задача** | напиши скрипт X, создай игру | 30-60 сек |

### ⚡ Умная маршрутизация

Роутер сам определяет куда направить задачу:

- uptime, df -h, ls → **bash прямо в Termux** (1 сек)
- открой вк, открой ютуб → **приложение** через a11y-сервис (2 сек)
- открой гитхаб, google.com → **браузер** (2 сек)
- напиши скрипт..., создай игру → **DeepSeek** + автономное выполнение

### 🤖 Свободный режим (главная фича)

**Плавающая кнопка поверх всех приложений** + полуавтоматический цикл:

1. Пишешь задачу в DeepSeek
2. DeepSeek отвечает кодом в блоке
3. **Копируешь блок**
4. **Тапаешь зелёную ●**
5. Кнопка → жёлтая → выполняет → **результат сам вставляется в DeepSeek**
6. Ты жмёшь «Отправить» сам

**Кнопка ● двигается пальцем, долгий тап — скрывает.**

### 🛠 Автономная разработка

~~~bash
ai-dev "добавь кнопку Экспорт в настройки"
~~~

DeepSeek:
1. Читает исходники
2. Создаёт патчи
3. Применяет
4. **Собирает APK** через build.sh
5. Если упало — исправляет и пересобирает

**Ты просто устанавливаешь готовый APK.**

### 📚 Прочее

- **3 темы** — светлая / тёмная / системная
- **Wizard первого запуска** с чек-листом окружения
- **Встроенная документация** — 6 документов внутри приложения
- **История задач** с деталями (повтор / копирование / удаление)
- **Уведомления** о завершении

## Установка

### Что нужно (вручную)

1. **Termux** — F-Droid (нет в Google Play): https://f-droid.org/packages/com.termux/
2. **Termux:API** — F-Droid: https://f-droid.org/packages/com.termux.api/
3. **DeepSeek** — Google Play

### Установка ассистента

~~~bash
# 1. Клонировать репозиторий
git clone https://github.com/CR4CODE/termux-assistant-ai.git
cd termux-assistant-ai

# 2. Установить скрипты и промпты
bash release-utils/install.sh

# 3. Установить APK (из Releases репозитория)
# Скачай → установи вручную

# 4. В приложении: Настройки → AI Bridge Service → включить
~~~

Подробнее — в **docs/INSTALL.md**

## Сборка из исходников

~~~bash
cd termux-assistant-ai
bash setup.sh              # скачает android.jar, создаст keystore
cd app
bash build.sh              # соберёт APK
# Результат: /sdcard/Download/ai-tasker-build-*.apk
~~~

**Требования:**
- Termux с пакетами: aapt2, d8, apksigner, openjdk-21, zip
- ~50 МБ свободного места

## Команды Termux (шпаргалка)

~~~bash
# Управление сервисом
aictl-up              # подъём после ребута
aictl status          # статус
aib ping              # проверить APK-сервис
aib openurl "https://ya.ru"
aib openapp com.vkontakte.android

# Роутер
ai-router "uptime"
ai-router "открой вк"
ai-router "открой гитхаб"

# Автономная разработка
ai-dev "задача"
~~~
