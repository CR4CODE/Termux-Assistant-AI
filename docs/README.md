# Termux Assistant AI

Автономный AI-ассистент для Android: голосом или текстом даёшь задачу —
приложение выполняет через Termux + DeepSeek.

## Что умеет

- **Голосовой ввод** — тап на 🎤 и говори
- **Быстрые команды** (1-2 сек): bash, открытие приложений, сайтов
- **Автономная разработка** через DeepSeek (30-60 сек)
- **3 темы**: светлая / тёмная / системная
- **Всё в одном APK** — UI + accessibility-сервис

## Три канала команд

| Тип | Пример | Куда идёт | Время |
|---|---|---|---|
| bash | uptime, df -h, ls | локально | ~1 сек |
| intent | открой вк, открой ютуб | приложение | ~2 сек |
| url | открой гитхаб, google.com | браузер | ~2 сек |
| ai | напиши скрипт X | DeepSeek | 30-60 сек |

## Архитектура

    ┌──────────────────────────────┐
    │ Termux Assistant AI (APK)    │
    │ • UI (ввод, история, темы)   │
    │ • AiBridgeService (a11y)     │
    └──────────┬───────────────────┘
               │ /sdcard/ai-tasker/{inbox,outbox}
               ▼
    ┌──────────────────────────────┐
    │ Termux                       │
    │ • ai-tasker-daemon (следит)  │
    │ • ai-router (маршрутизация)  │
    │ • aib-auto (DeepSeek)        │
    │ • aib (управление сервисом)  │
    └──────────────────────────────┘

## Быстрый старт

1. Установить Termux + Termux:API (F-Droid)
2. Установить DeepSeek (Play Market)
3. `aictl-up` (подъём инфраструктуры)
4. Дать разрешения при первом запуске
5. Включить Accessibility для AI Bridge Service

Подробнее: см. INSTALL.md

## Требования

- Android 7+ (SDK 24)
- Termux + Termux:API
- DeepSeek (для AI-задач)

**Wi-Fi не требуется** — сокет работает через loopback.
