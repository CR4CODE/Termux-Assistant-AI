# Как пользоваться Termux Assistant AI

## Три способа поставить задачу

### 1. Голосом 🎤

- Тап на кнопку **🎤** справа от «Выполнить»
- Скажи чётко: «открой вк», «покажи время», «напиши скрипт ping»
- Текст появится в поле ввода
- Жми «Выполнить»

### 2. Текстом

Введи в поле → жми «Выполнить».

### 3. Голосом через системный ввод

Если у тебя есть системный ввод — работает как обычно.

## Что писать в поле

| Что хочешь | Что пишешь | Время |
|---|---|---|
| Узнать uptime | `uptime` | 1 сек |
| Свободное место | `df -h` | 1 сек |
| Список файлов | `ls ~/projects` | 1 сек |
| Открыть ВК | `открой вк` | 1 сек |
| Открыть YouTube | `открой ютуб` | 1 сек |
| Позвонить | `позвони 89261234567` | 1 сек |
| Открыть сайт | `открой гитхаб` | 2 сек |
| Открыть URL | `открой ya.ru` | 2 сек |
| Написать скрипт | `напиши скрипт...` | 30-60 сек |

## Просмотр результата

Тап по задаче в истории → **модалка**:
- Полный текст задачи
- Полный вывод (с моноширинным шрифтом)
- Время выполнения
- Кнопки: **Повторить** / **Копировать** / **Удалить**

## Три темы

**Настройки → Тема:**
- **Светлая** — белая
- **Тёмная** — чёрная (как в системе)
- **Как в системе** — автоматически

## Долгий тап на задаче

Долгое нажатие (1 сек) → диалог **«Удалить задачу?»** → подтверждение.

## Когда ждать долго

**AI-задачи** (те, что содержат «напиши», «создай», «сделай»):
- 30-60 секунд
- В истории видно ⏳ прогресс
- Termux сам откроет DeepSeek, отправит запрос, дождётся ответа, выполнит код

**Не закрывай Termux** и **не блокируй экран** пока идёт AI-задача.

## Что делать если задача зависла

1. **Открой Termux**
2. Проверь статус:

    aictl status

3. Если receiver мёртв:

    aictl-up

4. Посмотри лог:

    aictl log 50

5. Смотри логи последней задачи:

    cat /sdcard/ai-tasker/logs/daemon.log | tail -30

## Ежедневный сценарий

**Утром после ребута телефона:**

В Termux:

    aictl-up

Проверить статус:

    aictl status

Если порты OK — всё готово, пользуйся приложением.

**Вечером (опционально):**

    aictl stop

## Что важно

- **Termux должен быть активен** (не убит системой)
- **Экран не заблокирован** для AI-задач
- **DeepSeek приложение** должно быть установлено и залогинено
- **Не трогай телефон** во время AI-задачи

## Разрешения, которые нужны

| Разрешение | Для чего |
|---|---|
| Файлы и медиа | Обмен через /sdcard/ai-tasker |
| Микрофон | Голосовой ввод |
| Уведомления | Уведомления о завершении |
| Accessibility | Управление экраном (для AI-задач) |

- ❌ Wi-Fi

- ❌ Регистрация где-либо
