05

Технические решения

SOCKET ВМЕСТО ФАЙЛОВ

Android 11+ не даёт a11y писать в /sdcard/. Сокет 127.0.0.1 решает всё — нужно только INTERNET.

CANPERFORMGESTURES

Без флага в конфиге a11y жесты dispatchGesture уходят в никуда и Compose их игнорирует.

COMPOSE ACTION_CLICK

Кнопки Compose не реагируют на dispatchGesture. Работает только performAction на кликабельном родителе.

INPUT COMPOSE

Поле ввода — ViewFactoryHolder с TextView-плейсхолдером. EditText появляется только после тапа.

KEYSTORE ВНЕ BUILD/

keystore.jks в keys/, а не в build/ — иначе rm -rf build удаляет его, и подпись меняется.
