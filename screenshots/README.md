# Скриншоты

Здесь лежат скриншоты приложения для README.

## Какие нужны

1. **main.png** - главный экран (поле ввода, кнопки, свободный режим)
2. **history.png** - экран истории задач
3. **settings.png** - настройки (тема, инструкция, VK)
4. **free-mode.png** - плавающая кнопка поверх DeepSeek
5. **wizard.png** - экран первого запуска

## Как добавить

Скинь скриншоты в эту папку с указанными именами, потом:

    git add screenshots/*.png
    git commit -m "Add screenshots"
    git push
