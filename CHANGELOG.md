# Changelog

Все значимые изменения проекта.

## [2.0.0] — 2026-10-01

Полный редизайн интерфейса. Стиль синхронизирован с лендингом проекта.

### Добавлено

**Интерфейс:**
- Новая палитра: тёплый чёрный `#121214` + зелёный акцент `#22C55E`
- Полноценная светлая тема
- Шрифты Syne (заголовки) + JetBrains Mono (моноширинные блоки)
- Скругления, тонкие границы, ripple-эффект на кнопках
- Splash screen для Android 12+ (чёрный фон + зелёная точка)
- Иконка приложения: зелёная точка на чёрном фоне (adaptive + PNG fallback)

**Главный экран — чат-стиль:**
- Список задач в центре, как в ChatGPT/Claude
- Поле ввода приклеено снизу, кнопки 🎤 и → по бокам
- Приветствие с зелёной точкой, когда задач нет

**Live-лог Терминала:**
- Блок над списком задач показывает активность Termux в реальном времени
- Украшенный формат с иконками: ▶ задача, 💾 результат записан, ✅ готово, ❌ ошибка
- Сворачивается тапом по шапке

**Переключатель режимов AI / Dev / Shell:**
- 🤖 AI — задача в DeepSeek
- 🛠 Dev — автономная разработка APK через ai-dev
- ▶ Shell — прямое выполнение в Termux
- Выбор сохраняется в SharedPreferences

**История:**
- Поиск по задачам и выводу
- Кнопка «Удалить всё» (удаляет видимые после фильтра)
- Счётчик задач

### Изменено

- Свободный режим теперь выключен по умолчанию при холодном старте
- Overlay — круглый индикатор с цветовой обводкой вместо квадрата
- Служебные задачи ai-dev (`tile`, `auto:`) отфильтрованы из списка
- Кнопка «🐙 Репозиторий на GitHub» в настройках
- RadioButton темы подкрашены в зелёный акцент

### Исправлено

- История задач подхватывает выбранную тему (раньше оставалась тёмной)
- `empty_history` — исправлен краш при подключении (TextView → View)
- Микро-мерцание тёмного экрана при холодном старте в светлой теме
- Двойной `onResume` в MainActivity
- Заголовки в настройках, welcome, docs — единый стиль
- Позиционирование кнопки микрофона (обрезался текст)

## [1.0.0] — 2026-09-29

Первый публичный релиз.

### Добавлено

**Android-приложение:**
- Голосовой ввод (SpeechRecognizer, ru-RU)
- Три темы: светлая / тёмная / системная
- Wizard первого запуска с чек-листом окружения
- Встроенная документация (6 документов внутри)
- История задач с модальным окном
- Прогресс-бар для выполняющихся задач
- Уведомления о завершении
- Плавающая кнопка «Свободный режим» (🟢🟡🔴)
- Quick Settings Tile для шторки
- Accessibility Service для управления экраном

**Termux-инфраструктура:**
- `ai-router` — маршрутизация задач (bash / intent / url / ai)
- `ai-tasker-daemon` — демон, слушающий /sdcard/ai-tasker/inbox
- `ai-dev` — автономная разработка APK через DeepSeek
- `aib-auto` — автономный вайбкодинг в sandbox
- `aib` — управление APK-сервисом
- `grab` — парсинг код-блоков DeepSeek
- `ai-cycle` — автономный цикл

**Сборка:**
- `build.sh` — сборка APK одной командой
- `setup.sh` — установка окружения (android.jar + keystore)
- `install.sh` — установка скриптов для новых пользователей

### Известные ограничения
- Android 7+ (SDK 24)
- Требуется Termux + Termux:API из F-Droid
- Требуется приложение DeepSeek
- Для автономной разработки — подключение к интернету
