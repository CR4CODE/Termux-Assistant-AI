# Changelog

Все значимые изменения проекта.

## [1.0.0] — 2026-09-29

Первый публичный релиз.

### Добавлено

**Android-приложение:**
- Голосовой ввод (SpeechRecognizer, ru-RU)
- Три темы: светлая / тёмная / системная
- Wizard первого запуска с чек-листом окружения
- Встроенная документация (6 документов внутри)
- История задач с модальным окном
- Прогресс-бар для выполняющихся задач
- Уведомления о завершении
- Плавающая кнопка «Свободный режим» (🟢🟡🔴)
- Quick Settings Tile для шторки
- Accessibility Service для управления экраном

**Termux-инфраструктура:**
- `ai-router` — маршрутизация задач (bash / intent / url / ai)
- `ai-tasker-daemon` — демон, слушающий /sdcard/ai-tasker/inbox
- `ai-dev` — автономная разработка APK через DeepSeek
- `aib-auto` — автономный вайбкодинг в sandbox
- `aib` — управление APK-сервисом
- `grab` — парсинг код-блоков DeepSeek
- `ai-cycle` — автономный цикл

**Сборка:**
- `build.sh` — сборка APK одной командой
- `setup.sh` — установка окружения (android.jar + keystore)
- `install.sh` — установка скриптов для новых пользователей

### Известные ограничения
- Android 7+ (SDK 24)
- Требуется Termux + Termux:API из F-Droid
- Требуется приложение DeepSeek
- Для автономной разработки — подключение к интернету
